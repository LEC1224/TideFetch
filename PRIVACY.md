# TideFetch privacy policy

Effective: August 9, 2026

TideFetch is a local-first Android application. The project does not operate a
developer backend, user accounts, advertising system, or analytics service.

## Data the app accesses

- **Clipboard text:** while TideFetch is visible, it can inspect the clipboard
  for a web URL to fill the URL field. Clipboard contents that are not web URLs
  are ignored. The user can replace or clear the resulting text.
- **Submitted URLs and network data:** when the user presses Download, the URL
  and normal network request information are sent directly from the device to
  the source website and any hosts that website uses to deliver media. Those
  third parties process data under their own terms and privacy policies.
- **Downloaded media:** temporary files are processed locally and successful
  results are written to the device's shared media library. TideFetch does not
  upload downloaded files to the project developer.
- **Technical logs and preferences:** download logs and the selected theme are
  stored or held locally. Logs are sanitized to reduce exposure of query tokens,
  authorization headers, cookies, credentials, and private temporary paths.

## Collection and sharing by the project

The TideFetch project does not receive, collect, sell, or share personal data.
Network operators and source websites can still observe ordinary connection
information, including an IP address and requested resource, when the app makes
a user-requested download.

## Retention and deletion

The app keeps no remote copy of user information. Users can clear the URL and
technical log in the app, delete downloaded media with their media manager, and
remove local preferences and temporary app data by clearing TideFetch storage or
uninstalling the app.

## Children

TideFetch is not directed to children and does not knowingly collect children's
personal information.

## Contact and changes

Questions and policy changes are tracked through the public project repository:
<https://github.com/LEC1224/TideFetch>. Material changes will be documented in
the repository and take effect from the date shown in this policy.
