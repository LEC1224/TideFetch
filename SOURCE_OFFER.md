# Source code for TideFetch binaries

TideFetch is licensed under GNU GPL version 3. Each binary release is accompanied
by a version-matched `TideFetch-<version>-corresponding-source.zip` asset on the
same GitHub release page:

<https://github.com/LEC1224/TideFetch/releases>

For TideFetch 0.1.0-alpha.3, use:

<https://github.com/LEC1224/TideFetch/releases/tag/v0.1.0-alpha.3>

The source asset contains the TideFetch application source, build scripts,
license texts, notices, pinned upstream source snapshots, Termux recipes and
patches, and native dependency source caches. `SHA256SUMS` inside the package
allows its contents to be checked; a separate `.sha256` release asset checks the
outer ZIP.

The release notes identify the exact APK/source pairing and disclose the
historical youtubedl-android AAR reproducibility limitation. Source inquiries can
also be filed publicly at <https://github.com/LEC1224/TideFetch/issues>.
